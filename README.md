# IS

This repository contains the code used for my Independent Study Thesis at the College of Wooster as a Mathematics and Computer Science double major. Contained in this repository are the following packages:

- data and gconv_experiment: contains methods to extract and preproces MNIST and CIFAR datasets.
- experiment: contains the code to reproduce the experiments from Cohen and Welling in 2016.
- p4g:  contains adaptation of G-CNN from Cohen and Welling, 2016 to implement the P4G wallpapaer group.

Additionally, the repository also contains pre-trained models in the trained models folder
